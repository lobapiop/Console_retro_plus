# Project CRP - Console Retro Plus

## Présentation

Project CRP (Console Retro Plus) est un projet open source ayant pour objectif de concevoir une console portable de rétrogaming basée sur un Raspberry Pi 5.

Le projet ne consiste pas simplement à intégrer un Raspberry Pi dans un boîtier imprimé en 3D. L'objectif est de développer une console portable fiable, ergonomique, maintenable et entièrement documentée.

Chaque décision de conception est justifiée, documentée et versionnée afin de permettre à toute personne de reproduire ou d'améliorer le projet.

---

## Objectifs

* Concevoir une console portable de qualité.
* Fournir une documentation complète.
* Utiliser des composants standards et facilement disponibles.
* Concevoir un boîtier robuste et facilement réparable.
* Centraliser tous les fichiers de conception dans un dépôt Git unique.
* Rendre le projet reproductible par la communauté.

---

## Caractéristiques principales

* Raspberry Pi 5 (4 Go)
* Écran IPS 5 pouces
* Batocera
* Wi-Fi et Bluetooth intégrés
* Dock HDMI + USB-C
* Recharge USB-C Power Delivery
* Batterie offrant environ 6 heures d'autonomie
* Deux joysticks Hall Effect
* D-Pad
* Boutons ABXY
* Gâchettes L1/L2 et R1/R2
* Haut-parleurs stéréo
* Prise casque 3,5 mm
* Microphone intégré
* Ventilateur intégré (gestion configurable)
* Boîtier imprimé en PETG
* Architecture orientée maintenance

---

## Philosophie du projet

Project CRP repose sur quelques principes simples :

* documenter chaque décision ;
* privilégier la qualité à la compacité ;
* rendre chaque pièce remplaçable ;
* limiter le câblage manuel au strict nécessaire ;
* utiliser des composants standard autant que possible.

---

## Méthodologie

Le projet est développé selon les étapes suivantes :

1. Cahier des charges
2. Architecture matérielle
3. Choix des composants (BOM)
4. Conception du boîtier
5. Conception électronique
6. Prototype
7. Validation
8. Documentation finale

Chaque étape est validée avant de passer à la suivante.
