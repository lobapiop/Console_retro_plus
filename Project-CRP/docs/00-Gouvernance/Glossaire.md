## CAO — Conception Assistée par Ordinateur

La **CAO** désigne l’utilisation d’un logiciel pour concevoir, dessiner et vérifier des pièces ou des assemblages en deux ou trois dimensions.

Dans Project CRP, la CAO sera notamment utilisée pour créer :

- le gabarit mécanique de l’écran ;
- la coque de la console ;
- les supports internes ;
- les emplacements des boutons et des sticks ;
- les passages de câbles ;
- les trous de fixation ;
- le dock.

Le logiciel retenu pour Project CRP est **FreeCAD**, car il est libre, gratuit et adapté à un projet open source.

Une CAO détaillée ne doit être réalisée qu’à partir de dimensions fiables et vérifiées, afin d’éviter de concevoir une pièce autour d’un composant incorrectement identifié.
