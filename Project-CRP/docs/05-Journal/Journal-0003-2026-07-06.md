# Project CRP – Journal de développement 0003

Date : 6 juillet 2026  
Statut : préparation des essais ET001  
Sujet principal : préparation du gabarit mécanique et du cahier de tests

# 1. Contexte

La livraison des premiers composants du banc de test est attendue pour le mardi 7 juillet 2026.

En attendant leur arrivée, le travail devait initialement porter sur la création du gabarit mécanique du module d’affichage Elecrow dans FreeCAD.

L’objectif était de préparer un modèle 3D simplifié du module, sans commencer la coque définitive de Project CRP.

---

# 2. Choix du logiciel de CAO

Le logiciel retenu pour la conception mécanique de Project CRP est :

**FreeCAD**

Ce choix est motivé par les points suivants :

- logiciel libre ;
- gratuit ;
- disponible sur plusieurs systèmes d’exploitation ;
- adapté à un projet open source ;
- capable de produire des modèles 3D paramétriques ;
- possibilité d’exporter les modèles dans des formats standards comme STEP et STL.

---

# 3. Ajout au glossaire

Une entrée a été ajoutée au glossaire du projet.

## CAO — Conception Assistée par Ordinateur

La CAO désigne l’utilisation d’un logiciel pour concevoir, dessiner et vérifier des pièces ou des assemblages en deux ou trois dimensions.

Dans Project CRP, la CAO sera notamment utilisée pour créer :

- le gabarit mécanique de l’écran ;
- la coque de la console ;
- les supports internes ;
- les emplacements des boutons et des sticks ;
- les passages de câbles ;
- les trous de fixation ;
- le dock.

Une CAO détaillée ne doit être réalisée qu’à partir de dimensions fiables et vérifiées.

---

# 4. Réévaluation du plan mécanique de l’écran

Lors de la comparaison entre le plan mécanique précédemment trouvé et les photographies commerciales du module Elecrow commandé, un doute important est apparu concernant la correspondance exacte des deux modèles.

Les différences possibles concernent notamment :

- la forme du PCB ;
- la position des connecteurs ;
- le nombre et la position des boutons OSD ;
- les trous de fixation ;
- l’encombrement arrière ;
- la référence exacte du module.

Le cartouche du plan ne permet pas de confirmer avec certitude qu’il correspond au modèle `DLH04950B`.

---

# 5. Décision concernant le gabarit mécanique

Il a été décidé de ne pas commencer un gabarit mécanique détaillé avant la réception et l’identification du module réel.

Le plan précédemment trouvé est désormais classé comme :

> Document potentiellement correspondant, non validé.

Les dimensions suivantes ne sont donc plus considérées comme confirmées pour le produit commandé :

- largeur hors tout de 121,11 mm ;
- hauteur hors tout de 77,93 mm ;
- profondeur maximale de 13,94 mm ;
- position des trous de fixation ;
- position exacte des connecteurs.

Ces dimensions pourront servir de points de comparaison, mais pas de base définitive pour FreeCAD.

---

# 6. Règle appliquée

La décision respecte les principes de Project CRP :

- ne pas créer de complexité sans bénéfice démontré ;
- ne pas figer une implantation mécanique à partir d’informations incertaines ;
- valider les composants structurels par des données fiables ;
- conserver une traçabilité des hypothèses et des corrections ;
- éviter un travail de CAO qui devrait être entièrement refait.

# 12. Risques ouverts

- réception d’une variante différente du modèle étudié ;
- absence de référence claire sur le PCB ;
- plan mécanique non correspondant ;
- résolution 1024×600 nécessitant une configuration manuelle ;
- tactile non reconnu par Batocera ;
- problème de double sortie HDMI ;
- câbles trop encombrants pour la future coque ;
- profondeur réelle supérieure aux valeurs annoncées ;
- fixation mécanique difficile ;
- consommation réelle différente de la valeur constructeur.
