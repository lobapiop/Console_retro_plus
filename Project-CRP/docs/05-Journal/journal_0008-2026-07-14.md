# Project CRP – Journal de développement 0008

Date : 14 juillet 2026  
Statut : gabarit mécanique écran Elecrow démarré  
Sujet principal : création du gabarit FreeCAD du module écran Elecrow

---

# 1. Contexte

Après la réalisation de la majorité des tests ET001 sur l’écran Elecrow 5 pouces 1024×600, le test `TEST-J01 – Consommation électrique de l’écran` reste reporté dans l’attente d’un testeur USB.

En attendant cette mesure électrique, la suite logique du projet est le passage à l’intégration mécanique.

La décision prise est donc de démarrer le **gabarit mécanique FreeCAD de l’écran Elecrow**.

Ce gabarit ne constitue pas encore une coque de console.  
Il sert uniquement de référence mécanique fiable pour préparer les futures étapes de conception.

---

# 2. Objectif du gabarit

L’objectif du gabarit est de représenter fidèlement le module écran reçu afin de sécuriser la conception mécanique de Project CRP.

Le gabarit doit permettre de vérifier :

- l’encombrement réel du module ;
- la position des trous de fixation ;
- la position de la zone visible de l’écran ;
- la présence des pattes de fixation ;
- l’épaisseur réelle du module ;
- les zones fragiles liées aux nappes FPC ;
- l’encombrement des connecteurs ;
- le dégagement nécessaire pour les câbles ;
- la compatibilité future avec une coque cible de 25 à 30 mm d’épaisseur.

Rappel important :

> Le gabarit n’est pas une pièce finale.  
> Il sert à éviter de concevoir la console autour d’une représentation fausse de l’écran.

---

# 3. Données mécaniques retenues

Les mesures issues des tests ET001 sont utilisées comme base prioritaire.

| Élément | Valeur retenue |
|---|---:|
| Largeur totale du module | 121,31 mm |
| Hauteur totale du module | 95,47 mm |
| Épaisseur retenue | 13 mm |
| Hauteur du rectangle écran physique | 75,65 mm |
| Zone active visible approximative | environ 108 × 64,8 mm |
| Diamètre des trous de fixation | 3 mm |

La valeur d’épaisseur a été corrigée pendant la préparation du gabarit.

L’estimation précédente de 10 mm est remplacée par la mesure réelle suivante :

> Épaisseur retenue du module écran : 13 mm.

Cette mesure inclut le module écran complet, son PCB arrière et les composants saillants.
