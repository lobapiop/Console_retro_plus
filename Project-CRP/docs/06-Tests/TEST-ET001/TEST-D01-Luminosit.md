## 1. Objectif

Évaluer la plage de luminosité et le confort dans plusieurs conditions d’éclairage.

## 2. Procédure

Tester :

1. luminosité minimale ;
2. luminosité à environ 50 % ;
3. luminosité maximale ;
4. pièce sombre ;
5. éclairage intérieur normal ;
6. proximité d’une fenêtre sans soleil direct.
