Version : 0.1

Composant testé : Elecrow 5inch IPS HD Display-C 1024×600  
Référence attendue : DLH04950B  
Plateforme : Raspberry Pi 5 – 4 Go  
Système : Batocera  

---

## 1. Objectif

Vérifier que le produit reçu correspond au module commandé et qu’il ne présente aucun dommage visible.

## 2. Matériel nécessaire

- module Elecrow reçu ; 
- emballage et accessoires ; 
- téléphone ou appareil photo ;
- plan ou fiche produit disponible.

## 3. Procédure

1. Ne pas alimenter le module.
2. Photographier l’emballage, la face avant, la face arrière et les connecteurs.
3. Relever toutes les références présentes sur l’emballage et le PCB.
4. Vérifier visuellement la dalle, le PCB, les connecteurs et les nappes.
5. Comparer le contenu reçu avec la commande.
