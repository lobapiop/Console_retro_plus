# Project CRP – TEST-K01 – Dimensions principales du module

Version : 0.1  
Statut : réalisé  
Étude associée : ET001 – Module d’affichage  
Composant testé : Elecrow 5inch IPS HD Display-C 1024×600  
Référence attendue : DLH04950B  
Plateforme : Raspberry Pi 5 – 4 Go  
Système : Batocera  

---

## 1. Objectif

Relever les dimensions nécessaires au futur gabarit FreeCAD.

## 2. Matériel nécessaire

- pied à coulisse recommandé ;
- règle de secours ;
- module non alimenté ;
- plan mécanique trouvé.

## 3. Précautions

- ne pas serrer fortement le pied à coulisse sur la dalle ;
- ne pas appuyer sur les nappes ;
- mesurer plusieurs fois ;
- noter l’incertitude de mesure.
