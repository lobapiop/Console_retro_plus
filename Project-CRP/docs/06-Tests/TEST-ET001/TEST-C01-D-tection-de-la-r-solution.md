# Project CRP – TEST-C01 – Détection de la résolution

Version : 0.1  
Statut : à exécuter  
Étude associée : ET001 – Module d’affichage  
Composant testé : Elecrow 5inch IPS HD Display-C 1024×600  
Référence attendue : DLH04950B  
Plateforme : Raspberry Pi 5 – 4 Go  
Système : Batocera  

---

## 1. Objectif

Vérifier que Batocera utilise une résolution adaptée, idéalement 1024×600 à 60 Hz.

## 2. Procédure

1. Démarrer Batocera.
2. Relever la résolution détectée.
3. Vérifier la fréquence.
4. Vérifier l’orientation.
5. Redémarrer après toute modification.
6. Documenter précisément les paramètres ajoutés.

## 3. Résultats

| Élément | Valeur |
|---|---|
| Résolution détectée | 1024x600 |
| Résolution sélectionnée | 1024x600 |
| Fréquence détectée | 66 |
| Orientation | Paysage  |
| Configuration manuelle nécessaire | Non |
| Fichier modifié | Aucun |
| Paramètres ajoutés | Aucun |

## 4. Critères de réussite

- mode 1024×600 disponible ou mode alternatif sans déformation ;
- proportions correctes ;
- image complète ;
- configuration conservée après redémarrage.

## 5. Conclusion

Résultat : Réussi
