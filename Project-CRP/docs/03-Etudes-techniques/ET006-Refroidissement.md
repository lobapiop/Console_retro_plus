# Project CRP – Étude technique 006 – Refroidissement

Version : 0.1

---

## 1. Objectif

Cette étude évalue les besoins en refroidissement du système, notamment en cas d’utilisation prolongée du Raspberry Pi 5 et des composants associés.

## 2. Contraintes

- dissipation thermique dans un boîtier compact ;
- faible bruit ;
- consommation électrique limitée ;
- intégration simple sans gêner l’ergonomie.

## 3. Options envisagées

- ventilation passive par dissipation thermique ;
- ventilateur compact ;
- dissipateur thermique sur composants clés.

## 4. Recommandation provisoire

Une solution passive associée à un ventilateur compact de faible consommation paraît suffisante pour un premier prototype.

## 5. Questions ouvertes

- température maximale acceptable ;
- présence de trous d’aération dans le boîtier ;
- besoin d’un ventilateur actif ou non.

## 6. Statut

Étude ouverte.
