# Project CRP – Étude technique 002 – Ergonomie et commandes

Version : 0.1

---

## 1. Objectif

Cette étude définit l’organisation des commandes et la prise en main du système afin d’assurer une expérience confortable et intuitive.

## 2. Contraintes

- console portable et compacte ;
- usage à une main possible ;
- boutons accessibles sans gêne ;
- intégration possible avec un RP2040 ou une carte d’interface dédiée ;
- possibilité de conserver un design fidèle à l’esthétique rétro.

## 3. Éléments à définir

- nombre de boutons principaux ;
- présence de boutons latéraux ou d’un pavé directionnel ;
- type de commandes : boutons mécaniques, interrupteurs ou capteurs ;
- disposition des boutons pour l’usage en jeu ;
- emplacement des connecteurs de commande.

## 4. Recommandation provisoire

Une architecture simple avec un pad directionnel, un ensemble de boutons d’action et un bouton d’option/menus paraît adaptée au concept.

## 5. Questions ouvertes

- nombre exact de boutons ;
- choix entre boutons mécaniques et interrupteurs ;
- besoin d’un stick analogique ;
- intégration d’un bouton d’alimentation ou de reset.

## 6. Statut

Étude ouverte, à valider par prototypage rapide.
