# Project CRP – Étude technique 007 – RP2040

Version : 0.1

---

## 1. Objectif

Cette étude précise le rôle du RP2040 dans l’architecture du système, notamment pour la gestion des entrées, l’éclairage ou les interfaces annexes.

## 2. Contraintes

- faible consommation ;
- intégration simple avec la carte principale ;
- capacité à gérer les entrées de commande ;
- possibilité d’évoluer vers une version plus complète ensuite.

## 3. Fonctions possibles

- lecture des boutons et commandes ;
- gestion d’indicateurs LED ;
- communication avec le Raspberry Pi 5 ;
- pilotage d’un mini écran ou d’un système d’interface utilisateur.

## 4. Recommandation provisoire

Le RP2040 est un bon candidat pour superviser les commandes et les fonctions annexes, sans prendre en charge le traitement principal du système.

## 5. Questions ouvertes

- protocole de communication à adopter ;
- nombre de lignes d’entrée/sortie nécessaires ;
- besoin d’un firmware spécifique dès la première version.

## 6. Statut

Étude ouverte.
