# Project CRP – Étude technique 005 – Audio

Version : 0.1

---

## 1. Objectif

Cette étude examine les besoins audio du système et les contraintes d’intégration dans le boîtier.

## 2. Contraintes

- qualité audio suffisante pour les jeux et les médias ;
- faible consommation électrique ;
- intégration compacte dans la structure ;
- simplicité de branchement sur le système embarqué.

## 3. Options envisagées

- mini haut-parleur mono ;
- haut-parleur stéréo compact ;
- sortie audio vers casque via connecteur jack.

## 4. Recommandation provisoire

Un module audio compact avec haut-parleur intégré et sortie casque semble être un bon compromis.

## 5. Questions ouvertes

- volume sonore souhaité ;
- présence d’un jack 3,5 mm ;
- besoin d’une amplification dédiée.

## 6. Statut

Étude ouverte.
