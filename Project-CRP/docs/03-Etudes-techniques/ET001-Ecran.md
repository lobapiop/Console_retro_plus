# Project CRP – Étude Technique ET001

# Écran

Version : 0.1

---

# 1. Objectif

Cette étude a pour objectif de sélectionner l'écran qui équipera Project CRP.

L'écran est un composant structurant du projet. Son choix influencera :

* les dimensions du boîtier ;
* l'ergonomie générale ;
* la consommation électrique ;
* la batterie ;
* le système de refroidissement ;
* le coût global.

La sélection devra être réalisée selon la méthode de décision définie dans **CRP-Methode-de-decision.md**.

---

# 2. Besoin fonctionnel

L'écran devra permettre une utilisation confortable des principaux systèmes émulés par Project CRP :

* Game Boy
* Game Boy Color
* Game Boy Advance
* Nintendo DS
* PSP
* Dreamcast
* GameCube (dans la limite des capacités du Raspberry Pi 5)

L'écran devra également offrir une bonne lisibilité en intérieur.

---

# 3. Exigences obligatoires

## Taille

* 5 pouces (objectif)

Une légère variation (5,2" ou 5,5") pourra être acceptée si les avantages sont significatifs.

---

## Technologie

IPS ou AMOLED.

Les deux technologies sont acceptées.

---

## Interface

HDMI obligatoire.

Le tactile n'est pas une exigence.

---

## Orientation

Compatible paysage.

Une rotation logicielle est acceptable.

---

## Alimentation

5 V.

---

## Compatibilité

Compatible Raspberry Pi 5 sans développement spécifique.

---

## Disponibilité

Le produit doit être :

* disponible chez plusieurs revendeurs ;
* facilement commandable en Europe.

---

## Documentation

Une documentation constructeur doit être disponible.

---

# 4. Exigences souhaitables

* dalle capacitive (même si le tactile ne sera pas utilisé immédiatement) ;
* faible consommation électrique ;
* angles de vision élevés ;
* bonne luminosité ;
* faible épaisseur ;
* fixation simple.

---

# 5. Critères de comparaison

Les écrans seront comparés selon les critères suivants :

| Critère                    | Pondération |
| -------------------------- | ----------: |
| Compatibilité Raspberry Pi |        30 % |
| Intégration mécanique      |        20 % |
| Maintenance                |        15 % |
| Disponibilité              |        15 % |
| Documentation              |        10 % |
| Prix                       |        10 % |

---

# 6. Candidats retenus

Les candidats actuellement identifiés sont :

* Raspberry Pi Touch Display 2 (5")
* Waveshare 5" HDMI IPS
* Waveshare 5.5" HDMI AMOLED
* Elecrow 5" HDMI IPS

Cette liste pourra évoluer au cours de l'étude.

---

# 7. Informations à collecter

Pour chaque écran, les informations suivantes devront être relevées :

* référence exacte ;
* dimensions hors tout ;
* dimensions de la dalle visible ;
* épaisseur ;
* poids ;
* consommation ;
* résolution ;
* luminosité ;
* position des connecteurs ;
* présence ou non d'une carte contrôleur séparée ;
* disponibilité ;
* prix moyen.
